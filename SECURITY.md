# Security Policy

## Supported versions

Security fixes are provided for the latest generally available Log Source Watch release unless a commercial agreement states otherwise.

## Reporting a vulnerability

Please do **not** open a public GitHub issue for a suspected security vulnerability.

Until a dedicated security mailbox is published, use the private security-reporting channel configured for this repository or contact the project owner through the product website:

https://logsourcewatch.com/

Include:

- affected version
- reproduction steps
- expected and observed behavior
- security impact
- any proof-of-concept material

Please avoid including customer data, credentials, private keys, or sensitive Splunk content.
